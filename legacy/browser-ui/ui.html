Images to Encrypted PDF

Decrypt archive · batch compress · build PDF · encrypt, all in one pass

Everything runs on your own computer. No network, no uploads. Archive and PDF passwords stay local; never share them.

1Select images

Saved next to the archive/folder as `images_encrypted.pdf` by default.

2Compression and reading

The app assigns a per-image budget from the target size and picks the highest fitting quality, recompressing if needed. For screenshots or receipts with small print, use 2000 px and quality 90.

3PDF open password

Uses AES-256. Share the password separately by phone or SMS, never in the same chat as the PDF. If an old phone reader cannot open it, generate without a password and add AES-128 with Stirling-PDF.
