# Code of Conduct

## Our pledge

We want this project to be an open, friendly place. Everyone — maintainers,
contributors and users asking questions — is treated with respect regardless of
experience level, language, region or identity.

## Expected behaviour

- Stay on topic and give reproducible steps, logs and environment details.
- Ask questions in English or Simplified Chinese; write clearly so others can help.
- Respect privacy: do not upload other people's private photos, archives or
  passwords; strip personal paths before submitting a report.
- Accept constructive feedback and keep technical discussion evidence-based.

## Unacceptable behaviour

- Personal attacks, discrimination, harassment, or publishing someone else's
  private information.
- Pasting passwords, keys or sensitive files into issues or pull requests.
- Using this project to spread malware, bypass encryption or infringe copyright.

> This tool is only for images you are entitled to process. Do not use it to
> distribute unauthorised material.

## Reporting

If you encounter inappropriate behaviour, contact the maintainer through a
private channel. Do not repeat personal details in a public issue. Reports are
handled confidentially; content may be removed or access restricted.
